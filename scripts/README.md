# Scripts

Reusable Python code imported by the notebooks. These modules should be written for reproducibility and modularity, and kept separate from notebook-only exploratory work.

- `data_access/`: CMIP6/CMIP7 loaders and ancillary data
- `preprocessing/`: regridding, time handling, model selection, and region masks
- `diagnostics/`: data availability summaries and ensemble statistics
- `plotting/`: plotting helpers (empty for now)
