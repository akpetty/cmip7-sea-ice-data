# CMIP7 Sea Ice Data notebooks

This directory is reserved for exploratory notebooks, analysis notebooks, and figure development workflows.

Suggested organization:
- `00_getting_started/`: onboarding and environment notes
- `01_data_access/`: dataset discovery and remote access checks
- `02_processing/`: preprocessing and QC workflows
- `03_analysis/`: scientific analyses and diagnostics
- `04_plotting/`: final plotting and figure generation

Keep notebooks readable and annotate any assumptions, provenance, or data source details.
