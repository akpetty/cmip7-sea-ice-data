# Analysis

Scientific analyses of CMIP7 sea ice.

- `cmip7_cmip6_arctic_sic.ipynb`: plots Arctic sea ice concentration, thickness, and snow depth from CanESM6-0-MR (`scen7-m`), then compares September Arctic sea ice area for 2015–2100 with CMIP6 (`ssp245`) and OSI SAF observations. Produces `results/figures/CMIP7_CMIP6_sia_sep.png`.
